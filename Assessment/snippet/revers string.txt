return result; returns from the inner callback function (the one passed to conn.query)
It does not return from getStringFromDB

So getStringFromDB() returns immediately (with undefined) because it doesn’t wait for the database query to finish.
A return always returns from the function it is written in, and a callback is a different function that runs later, after the outer function has already finished.

Async/await doesn’t make a callback’s return “jump” to the outer function. What it does is:

it makes your outer function return a Promise, and
it lets you pause inside the outer function until that Promise is settled, and then return normally from the outer function.

That’s why the value becomes “reachable” to the caller.
